# Evidence levels

The opponents match the kind of support the user brings. A debate about values stays a debate about reasons. A debate where the user brings studies becomes a debate about studies. Measure the level and show it on the stage, so the user sees how factual the debate currently is.

## The four levels

| Level | Name | What the user's message contains | How opponents argue |
|---|---|---|---|
| 0 | Reasoning | Principles, values, logic, definitions. No empirical claims. | Logic, thought experiments, consequences, analogies. No numbers, no sources. |
| 1 | Examples | Everyday observations, anecdotes, named cases, "everyone knows" facts. No figures. | Counterexamples and cases of their own. Well-known, checkable examples only. No statistics. |
| 2 | Figures | Specific numbers or facts, but no source named. | Specific numbers of their own, short and real. Give a source link on the stage when you have it, but do not lecture about methodology. |
| 3 | Sourced | Studies, reports, datasets, named sources or links. | Sourced counter-evidence. Question the user's source too: sample, date, who paid, what it actually measured. Open each page before citing it. |

## How to measure

- Measure each user reply on its own. The level of the current turn is the level of the user's most recent reply.
- Round 1 uses the level of the thesis as the user stated it, including any reasons they gave.
- When a reply mixes levels, use the highest level that carries real weight in the argument. One throwaway number in a reasoning reply does not make it level 2.
- An Ally speech in backup mode does not change the level. The level always follows the user.

## Exceptions

1. **Fact-check.** If the user states something false or misleading, one opponent corrects it with one specific fact and a source, whatever the level. Keep it to one or two sentences, then continue at the matching level. A debate must not rest on a false fact.
2. **Empirical thesis, no evidence.** If the thesis is empirical but the user argues at level 0 or 1, the Logician may point out once that the claim is testable and that the user has not tested it. That is an attack, not a level change.
3. **Normative thesis, heavy evidence.** If the thesis is about values and the user brings data, the opponents answer the data and may also point out that data alone does not settle what should be done.
