# Nova SBE research sources

Tier B reference for Nova SBE students. Load it only after tier A search (open-sources.md) is done and only for sub-questions that tier A could not answer well.

## Access routes

| Code | Meaning | What the student does |
|---|---|---|
| A | Open source, Claude fetches it directly | Nothing |
| B | Licensed, student logs in and exports | Opens the link, searches the given terms, downloads the named file, uploads it to the chat |
| C | Licensed, the library lists on-campus access | Check the library page for current access options before suggesting a lookup |
| T | Licensed, only on campus terminals, desktop software or the Social Sciences DataLab | Same as B, but on a Nova machine or via the DataLab |

Never ask for passwords. Never log in on the student's behalf. Every B or T task names the database, the exact link, the search terms and the file to export.

Use the library page to check the current access route for each licensed database; login and off-campus availability vary. General off-campus guidance: https://library.novasbe.unl.pt/off-campus-access/

## Not useful for business coursework

ACS, AIP, IOP, Royal Society of Chemistry, IEEE Xplore, PsycINFO, PsycARTICLES, OECD Health Data, SHARE, WHO, EU Law Live (law students only), UNWTO and Greenleaf only for tourism or sustainability topics.

## Rules for papers

1. Give the DOI link, never a guessed URL.
2. Check for a free legal version first (author page, SSRN, institutional repository) and link it.
3. If none exists, point to Nova SBE Discovery with the exact title as search term.
